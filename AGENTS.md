# Project Context

This is a personal learning project. Keep process lightweight and support understanding and experimentation with the skills.

The current design baseline is in:

- `docs/product-requirements.md`
- `docs/architecture.md`
- `docs/database-schema.md`
- `docs/milestone-1.md`
- `docs/testing-and-evaluation.md`

Read relevant existing documents before planning or implementing changes. Preserve and extend these documents where useful; avoid unnecessary duplication or replacement. Identify inconsistencies between new proposals and existing decisions. Respect each document's approval status: proposed architectural choices become final ADRs only with explicit user approval.

Within an approved implementation task, modify code, tests, and documentation as needed without requesting permission for every file. Ask for approval before creating GitHub Issues, pushing, merging, or making significant architectural changes.
